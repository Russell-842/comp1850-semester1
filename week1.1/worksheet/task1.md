# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location/folder of the terminal|
|     ls                      | lists all files/directories in the current directory|
|     cd directory_name       | changes the current working directory to folder directory_name|
|     cd ..                   | moves up one directory level|
|     cd -                    | switches back to previous directory you worked in|
|     mkdir directory_name    | creates a new directory/folder called 'directory_name' in current location|
|     touch filename          | creates a new empty file called '(filename)'|
|     git status              | shows current state of Git repository e.g unstaged & staged changes to commit|
|     git add -A              | stage all changes in entire repository(new/modified/deleted files), prep for commit|
|     git commit -m ""        | creates/saves new commit using staged changes and attaches messages within " "|
|     git push                | sends changes made back to remote Github server|
|     git pull                | fetches and integrates changes from a remote repository into current branch|
